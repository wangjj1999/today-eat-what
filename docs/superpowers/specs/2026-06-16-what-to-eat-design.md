# 今天吃什么 — 设计规格说明

> **日期:** 2026-06-16 | **状态:** 待实施

## 1. 项目概述

一个纯前端网页应用，帮助选择困难症用户从学校附近收录的食物选项中，通过随机抽奖方式决定今天吃什么。

## 2. 核心需求

| 维度 | 决策 |
|------|------|
| 抽取方式 | 纯随机（等概率） |
| 数据存储 | 浏览器 localStorage |
| 条目信息 | 仅名称（字符串） |
| 设备支持 | 响应式（手机 + PC） |
| 动画效果 | 三段式滚动抽奖（快速滚 → 减速 → 定格庆祝） |
| 管理功能 | 添加、编辑、删除 |

## 3. 技术方案

- **纯 HTML/CSS/JS 单文件**，零依赖，零构建
- 数据以 JSON 数组存储在 `localStorage`，key 为 `food-list`
- 动画使用纯 CSS transition/keyframes + JS `setInterval`/`setTimeout`

```js
// localStorage key: "food-list"
// 结构：纯字符串数组，按添加顺序
// 用户可自行在名称中加入 emoji（如 "🍜 兰州拉面"），应用不做自动添加
["兰州拉面", "黄焖鸡米饭", "沙县小吃", "麦当劳"]
```

## 6. 交互流程

### 6.1 添加食物
用户点击「+ 添加」→ 弹出模态框（含输入框）→ 输入名称 → 确认 → 名称加入数组末尾 → 列表刷新

### 6.2 编辑食物
用户点击某条目旁的 ✏️ → 弹出模态框（预填当前名称）→ 修改 → 确认 → 数组对应位置更新

### 6.3 删除食物
用户点击某条目旁的 🗑️ → 弹出确认"确定删除「XXX」？"→ 确认后从数组移除

### 6.4 抽奖
用户点击「🎲 开抽」→ 三段式动画 → 展示结果，按钮变为「🔄 再来一次」

## 7. 动画规格

| 阶段 | 时长 | 行为 |
|------|------|------|
| 快速滚动 | ~1.5s | 名字以 80ms/个 快速切换 |
| 逐渐减速 | ~1.0s | 切换间隔递增至 300ms |
| 定格庆祝 | 持续 | 结果放大 + 弹跳动画 + emoji 飘散 |

- 动画期间按钮禁用，防止重复触发
- 仅 1 个选项时跳过滚动，直接展示提示

## 8. 边界状态

| 状态 | 处理 |
|------|------|
| 列表为空 | 抽奖区显示"还没添加吃的，先加点吧~"，按钮禁用 |
| 仅 1 个选项 | 不滚动，直接显示"就这一个，别犹豫了！" |
| 抽奖进行中 | 按钮禁用，忽略点击 |
| 添加/编辑时输入为空 | 确认按钮禁用，或 toast 提示"名称不能为空" |
| localStorage 不可用 | 静默降级为内存数组（本次会话有效） |

## 9. 文件结构

```
今天吃什么.html    ← 唯一的文件，包含所有 HTML/CSS/JS
```

## 10. 非功能需求

- 首次打开速度 < 1 秒（无外部资源，应 < 100ms）
- 支持添加到手机主屏幕（PWA 可选，非必需）
- 动画流畅，60fps
- 代码总量预计 < 400 行
