## 🍔 三种技术方案对比

同一个需求，三种实现路径 — 点击你倾向的方案

A

纯 HTML/CSS/JS 单文件

一个 .html 文件搞定一切，双击打开就能用。零依赖、零安装、零构建。

Pros

  • 无需安装任何工具
  • 双击浏览器就能打开
  • 极其轻量（几十KB）
  • 可以存手机桌面当 App 用

Cons

  • 代码都在一个文件里
  • 后续加复杂功能会稍乱
B

Alpine.js 单文件

同样是单文件，但引入 Alpine.js CDN 获得响应式数据绑定，代码组织更清晰。

Pros

  • 无需构建工具
  • 响应式数据，代码更干净
  • 扩展性好

Cons

  • 依赖 CDN（离线不可用）
  • 引入约 50KB 外部库
C

React + Vite SPA

现代化前端工程方案，组件化开发，为未来扩展留足空间。

Pros

  • 组件化，扩展性最强
  • 丰富的动画库可选
  • 后续加后端很方便

Cons

  • 需要 Node.js 环境
  • 构建后才能部署
  • 对这么简单的需求来说偏重
