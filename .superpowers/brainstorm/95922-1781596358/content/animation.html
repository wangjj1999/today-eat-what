🎰 抽奖动画流程

点"开抽"后的完整动画时序

1

快速滚动 (1.5 秒)

食物名字在抽奖框中以约 80ms/个 的速度快速切换，像老虎机转轮。名字随机出现，制造悬念。

兰州拉面 → 黄焖鸡 → 沙县 → 麦当劳 → ...
2

逐渐减速 (1 秒)

切换速度从 80ms 逐渐降到 300ms，名字变换越来越慢，紧张感拉满。

... 沙县 ... 兰州 ... 黄焖鸡 ...
3

🎉 定格结果 + 庆祝效果 (持续展示)

最终名字放大显示，配合轻微弹跳动画 + emoji 撒花（🍜✨🎉），持续展示直到用户下次操作。

🎉 黄焖鸡米饭 🎉

🎯 动画技术方案

  • 纯 CSS + JS setTimeout — 名字切换用 setInterval 控制，减速用递增延迟
  • 结果弹跳 — CSS @keyframes bounce，简单一个动画类
  • Emoji 撒花 — 用 JS 在结果周围随机生成几个 emoji 元素，CSS 动画飘散
  • 无外部依赖 — 全部手写，几十行代码搞定
